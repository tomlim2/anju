# TYPE TAPE

입력한 문장이 3D 리본을 타고 흐르는 타이포그래피 랩. 밴드·뫼비우스·코일
곡면 위에 셀 셰이딩과 스크린톤으로 인쇄된 활자가 돈다.

cel-lab의 인쇄 언어(밴드 라이팅, 디바이스 공간 하프톤, 하드 룰)를
타이포그래피에 적용한 세 번째 web 실험.

## 실행

```bash
node web/type-tape/serve.mjs 7400
```

`http://127.0.0.1:7400`. ES 모듈이라 파일로 직접 열면 동작하지 않는다.
three.js는 importmap CDN (빌드 단계 없음).

## 구조

```
index.html      마크업 + 컨트롤 덱
styles.css      cel-lab 셸 + 텍스트 입력
serve.mjs       정적 서버
src/
├── main.js           덱 배선 — 입력 디바운스(IME), 슬라이더
├── scene.js          파라메트릭 곡면 3종, 카메라, 모션
├── tape-material.js  리본 셰이더 (GLSL)
└── text-texture.js   문장 → 심리스 반복 텍스처
```

## 동작 방식

- **문장 텍스처** — 문장을 캔버스에 한 번 그린다. 캔버스 폭 = 문장 폭 + 여백
  정확히 한 타일이라 `RepeatWrapping`으로 이어 붙여도 이음매가 없다.
  알파 채널만 쓰고 색은 셰이더가 입히므로 텍스처 하나로 모든 팔레트를 감당.
  한글·한자는 브라우저 래스터라이저가 처리 — 폰트 파일 없음.
- **곡면** — 셋 다 u = 테이프 길이 방향, v = 폭 방향으로 UV를 맞춘
  `ParametricGeometry`. 그래서 문장 텍스처와 에지 룰이 곡면과 무관하게
  동일하게 동작한다. 각도는 시계 방향 — 카메라가 주로 보는 바깥 면이
  정방향으로 읽히고, 반대편은 유리창 너머 활자처럼 반전된다.
- **셰이더** — 양면 렌더에서 `gl_FrontFacing`으로 노멀을 뒤집어 뒷면도
  올바로 셰이딩. 3밴드 라이팅, 그늘 밴드엔 45도 하프톤 도트(디바이스 공간,
  `fwidth` 안티에일리어싱). 글리프는 라이팅과 무관하게 잉크 원색 유지 —
  인쇄물은 그늘에서도 글자가 또렷하다. 리본 양 가장자리에 필름 스트립처럼
  잉크 룰.
- **IME 디바운스** — 한글 조합 입력이 끝나길 180ms 기다렸다가 텍스처를
  다시 굽는다.

## 컨트롤

| 카드 | 항목 |
| --- | --- |
| TEXT | 문장 입력 (한글/한자/영문), HEAVY/REGULAR |
| SURFACE | BAND / MÖBIUS / COIL |
| MOTION | FLOW (텍스처 흐름 속도·방향), SPIN (회전) |
| PRINT | REPEAT (타일 수), TONE (하프톤 커버리지), EDGE RULE (가장자리 룰 폭) |
| INK | MANGA / REVERSE / RUBINE |
