# MONOLITH

모노크롬 복셀 타이포그래피 사이트. 한글·영문·한자를 캔버스로 래스터화한 뒤,
수천 개의 인스턴스 큐브 격자로 다시 세운다. 스크롤로 섹션이 바뀌면 큐브가
흩어졌다가 다음 단어로 재조립된다.

## 실행

```bash
node web/monolith/serve.mjs
```

`http://127.0.0.1:7200`. ES 모듈이라 `index.html`을 파일로 직접 열면 동작하지
않는다. three.js는 importmap으로 CDN에서 받는다 (빌드 단계 없음).

## 구조

```
index.html      마크업 + importmap
styles.css      모노크롬 셸 (종이 1색 / 잉크 2색)
serve.mjs       정적 서버
src/
├── main.js       페이지 배선 — 활성 패널이 단어를 정한다
├── scene.js      three.js 씬, InstancedMesh, 모프 애니메이션
└── type-field.js 글리프 샘플링 (캔버스 → 점군)
```

## 동작 방식

1. 오프스크린 2D 캔버스에 단어를 그린다. 브라우저 자체 래스터라이저를 쓰므로
   한글·라틴·한자가 동일하게 처리되고, 타입페이스 파일을 따로 싣지 않는다.
2. 알파 채널을 격자로 훑어 불투명한 픽셀만 점으로 남긴다.
3. 점 개수가 인스턴스 예산(5,200)을 넘으면 격자 간격을 넓혀 다시 훑는다.
   조밀한 점군을 무작위로 솎아내면 획이 끊기지만, 간격을 넓히면 획은
   그대로인 채 큐브만 굵어진다.
4. 큐브 한 변은 격자 간격에 비례한다. 상수로 두면 짧은 단어에서 큐브가
   서로 겹쳐 한 덩어리로 뭉친다.
5. 단어가 바뀌면 인스턴스는 생성·파괴 없이 이동만 한다. 각 큐브가 해시로
   정해진 자기 박자에 출발하고 비행 중 z축으로 부풀어, 잘려 바뀌는 대신
   흩어졌다 모인다.

## 조정 지점

| 위치 | 상수 | 의미 |
| --- | --- | --- |
| `scene.js` | `INSTANCES` | 큐브 예산. 샘플링 해상도의 상한 |
| `scene.js` | `MORPH_SECONDS` / `STAGGER` | 전환 길이와 출발 시차 |
| `scene.js` | `BASE_YAW` / `BASE_PITCH` | 기본 3/4 회전. 0이면 실루엣이 납작해진다 |
| `type-field.js` | `RASTER_HEIGHT` | 래스터 해상도. 획 디테일 |

단어는 마크업에서 온다 — 각 `.panel`의 `data-word`(필드에 세울 글자)와
`data-latin`(상단 상태 표시).

`prefers-reduced-motion`이 켜져 있으면 모프와 표류 회전을 건너뛰고 즉시
다음 단어로 바꾼다.
