# 폴더 규칙

anju 레포에서 폴더를 만들고, 옮기고, 지우는 규칙. 사람과 에이전트 모두 이 문서를 기준으로 판단한다.

## 1. 분류 축

최상위 폴더는 **기술/런타임** 기준으로 나눈다. 프로젝트 이름이나 작업 시기로 나누지 않는다.

| 최상위 | 담는 것 |
| --- | --- |
| `python/` | UE Python 모듈 |
| `web/` | 브라우저 정적 사이트·랩 |
| `webgl/`, `interactive/` | WebGL / 인터랙티브 실험 |
| `glsl/`, `hlsl/` | 셰이더 원본 |
| `bat/`, `sh/`, `ps1/` | 플랫폼별 스크립트 |
| `module/` | 언어 무관 재사용 모듈 |
| `ae/` | After Effects 스크립트 |
| `api-test/`, `hackathon/` | 실험·일회성 작업 |
| `csv/`, `parameters/`, `logs/` | 데이터·산출물 |
| `guidelines/` | 이 문서 같은 규칙 문서 |

## 2. 네이밍

- **최상위**: 소문자 한 단어. 하이픈·언더스코어 없음 (`web`, `glsl`, `ps1`).
- **`python/` 하위**: `snake_case` (`asset_manager`, `sm_path_to_csv`).
- **그 외 하위**: `kebab-case` (`micro-graphic-generator`, `cel-lab`, `nz-downloader`).
- 버전·날짜·`new`·`test`·`final` 같은 수식어를 폴더명에 넣지 않는다. 그건 브랜치와 커밋이 할 일이다.

## 3. 폴더를 만드는 조건

셋 다 만족할 때만 새 폴더를 만든다.

1. 파일이 2개 이상이거나, 곧 2개 이상이 된다.
2. 독립적으로 실행·사용되는 단위다.
3. 기존 폴더 어디에도 자연스럽게 들어가지 않는다.

파일 하나짜리는 폴더로 감싸지 않고 상위에 그대로 둔다 (`glsl/rippleFragment.glsl` 처럼).

**최상위 폴더 신설은 마지막 수단이다.** 기존 축에 넣을 수 없다는 근거를 커밋 메시지에 남긴다.

## 4. 만들 때 같이 넣는 것

- 실행 단위(앱·모듈·랩)에는 `README.md`를 반드시 넣는다. 목표 / 실행 방법 / 현재 범위 3개 항목이 최소 구성이다.
- 빈 폴더는 커밋하지 않는다. 자리만 잡아야 하면 `.gitkeep`을 넣고, 실제 파일이 들어오면 지운다.
- 산출물·비밀값·사용자별 설정이 생기는 폴더는 만들면서 `.gitignore`에 같이 등록한다.
- 모듈 간 의존을 만들지 않는다. 각 폴더는 단독으로 동작한다 (CLAUDE.md 원칙).

## 5. 옮기거나 이름을 바꿀 때

```bash
git mv old-name new-name
```

`mv` 후 `git add`가 아니라 `git mv`를 쓴다. 이동 뒤에는 반드시:

1. 경로 참조를 전부 찾아 고친다.
   ```bash
   grep -rn "old-name" . --exclude-dir=.git --exclude-dir=node_modules
   ```
2. `.gitignore`, `package.json`, 스크립트, 테스트 config의 경로를 갱신한다.
3. `CLAUDE.md`의 구조 트리를 갱신한다.

## 6. 지울 때

폴더 삭제는 **되돌리기 어려운 작업**이다. 순서를 지킨다.

1. **참조 확인** — 위 `grep`으로 다른 곳에서 쓰는지 먼저 본다. 참조가 남아 있으면 지우지 않는다.
2. **내용 확인** — `ls -R`로 안에 무엇이 있는지 직접 본다. 이름만 보고 지우지 않는다.
3. **추적되지 않는 파일 확인** — `git status`에 안 잡히는 로컬 전용 파일(설정, 데이터, 심볼릭 링크)이 있으면 삭제 전에 사용자에게 알린다.
4. **git으로 삭제** — `git rm -r <path>`. `rm -rf`는 추적되지 않는 폴더에만 쓴다.
5. **뒷정리** — `.gitignore` 항목, `CLAUDE.md` 구조 트리, 관련 스크립트에서 해당 경로를 제거한다.

에이전트는 사용자가 명시적으로 지시하지 않은 폴더를 삭제하지 않는다. "정리해줘" 는 삭제 권한이 아니다.

## 7. 문서 동기화

폴더를 추가·삭제·이름 변경하면 **같은 커밋 안에서** `CLAUDE.md`의 `## Structure` 트리를 갱신한다. 구조 트리와 실제 디렉터리가 어긋나면 그것 자체가 버그다.

## 8. 커밋

폴더 구조 변경은 내용 변경과 섞지 않고 별도 커밋으로 낸다.

```
chore(structure): move sm-path-to-csv under python/
```

## 체크리스트

폴더를 만들 때:

- [ ] 3장의 조건 3개를 만족하는가
- [ ] 이름이 2장 규칙을 따르는가
- [ ] `README.md`가 있는가
- [ ] 산출물/비밀값이 `.gitignore`에 들어갔는가
- [ ] `CLAUDE.md` 구조 트리를 갱신했는가

폴더를 지울 때:

- [ ] `grep`으로 참조를 확인했는가
- [ ] 안의 내용을 직접 봤는가
- [ ] 추적되지 않는 로컬 파일이 없는가
- [ ] `git rm`으로 지웠는가
- [ ] `.gitignore`와 `CLAUDE.md`를 정리했는가
