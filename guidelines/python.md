# UE Python 모듈 작성법

`python/` 아래 모듈에 해당한다. 규칙은 대부분 이미 코드가 지키고 있는 것을 적은 것이고,
갈라져 있는 지점은 "갈라져 있다"고 그대로 적었다.

## 실행 모델

**파일 하나가 곧 실행 단위다.** 통째로 돌리는 것이 규약이다.

```python
import unreal

selected_assets = unreal.EditorUtilityLibrary.get_selected_assets()
for asset in selected_assets:
    ...
```

`if __name__ == "__main__":`은 123개 파일 중 8개에만 있다. 나머지는 톱레벨에 로직을 그대로 둔다.
UE Python 콘솔이나 에디터 유틸리티에서 파일을 실행하는 사용 방식에 맞춘 것이므로, 새 스크립트도
이 형태를 따른다. 함수로 감싸고 호출부를 안 만들면 아무 일도 일어나지 않는다.

`argparse`를 쓰는 스크립트는 에디터 밖에서 도는 것들이다. 이건 `python/README.md`의
"에디터 밖에서 실행" 목록에 해당하며, 별개의 부류로 취급한다.

## 입력은 선택으로 받는다

인자나 설정 파일이 아니라 **에디터에서 선택한 에셋**이 기본 입력이다. 65곳이 이 방식이다.

```python
selected_assets: list[unreal.Object] = unreal.EditorUtilityLibrary.get_selected_assets()
```

- 여러 개를 다루면 리스트를 그대로 순회한다
- 하나만 다루면 `[0]`을 쓴다. 다만 선택이 비어 있으면 `IndexError`로 죽는다는 걸 알고 쓴다
- 타입 어노테이션(`: list[unreal.Object]`)은 39곳에서 쓰고 있다. 붙이면 에디터 자동완성이 산다

## 에셋 경로

`/Game/`으로 시작하는 경로 리터럴이 **622곳**에 하드코딩돼 있다. 프로젝트 구조가 바뀌면
전부 깨지는 상태다. 새로 쓰는 코드는 최소한 다음을 지킨다.

- 경로 리터럴은 **파일 상단에 상수로 모은다.** 로직 중간에 문자열을 박지 않는다
- 포워드 슬래시를 쓴다. 백슬래시는 UE 경로에서 쓰지 않는다
- Data Asset은 `DA_` 프리픽스를 붙인다

로컬 드라이브 경로(`D:\`, `E:\`)도 `python/`·`bat/`·`ps1/`을 합쳐 45곳에 있다.
이건 다른 PC에서 돌지 않는다는 뜻이다. 새로 넣지 않고, 넣어야 하면 파일 맨 위에 상수로 둔다.

## 에디터 API

구 API와 신 API가 섞여 있다. 어느 쪽이든 **한 파일 안에서는 하나로 통일한다.**

| | 호출 수 | 예 |
| --- | --- | --- |
| 라이브러리 (구) | 98 | `unreal.EditorAssetLibrary.load_asset(path)` |
| 서브시스템 (신) | 58 | `unreal.get_editor_subsystem(unreal.EditorAssetSubsystem)` |

새 코드는 서브시스템 쪽을 권한다. UE 5에서 라이브러리 계열이 점차 대체되고 있다.

에셋을 고쳤으면 저장까지 한다. 저장을 빠뜨리면 에디터를 닫을 때 조용히 사라진다.

```python
unreal.EditorAssetLibrary.save_asset(path)
```

경로를 조립해서 접근하기 전에는 `does_asset_exist()`로 확인한다. 22곳이 이미 그렇게 한다.

## 실패 처리

`try:`가 있는 파일은 123개 중 14개다. 나머지는 실패하면 그냥 스택 트레이스를 뱉는다.

이건 **의도된 것으로 본다.** 에디터에서 사람이 직접 돌리는 스크립트라 조용히 실패하는 것보다
터지는 편이 낫다. 그러니 다음만 지킨다.

- **빈 `except:`로 삼키지 않는다.** 무엇이 잘못됐는지 안 보이면 디버깅이 불가능해진다
- 되돌릴 수 없는 작업(에셋 삭제, 일괄 리네임) 전에는 대상 목록을 먼저 출력한다
- 부분 실패가 데이터를 망가뜨릴 수 있으면 그때만 `try`로 감싼다

## 모듈 경계

**모듈 간 import를 금지한다.** 각 모듈은 단독으로 동작한다. 다른 모듈의 함수가 필요하면
복사한다. 중복이 결합보다 낫다 — 브랜치마다 일부 모듈만 들어가는 사용 방식 때문이다.

## 스타일

- `snake_case`. 파일명도 모듈명도 같다
- **들여쓰기는 스페이스 4칸.** 현재 탭 19파일 / 스페이스 56파일로 갈려 있다. 새 파일은 스페이스로 쓰고,
  기존 파일을 고칠 때는 그 파일의 방식을 따른다. 한 파일 안에서 섞는 것이 가장 나쁘다
- `import unreal` 뒤에 세미콜론을 붙이지 않는다
