# csv — 캐릭터 프리셋 데이터

**UE 관련: 예 (데이터).** CINEV 캐릭터 프리셋 표. UE에서 내보냈거나 UE로 넣기 위한 중간 데이터다.

이 데이터를 다루는 코드는 [`../python/preset_manager/`](../python/preset_manager/)에 있다.
다만 현재 preset_manager 코드가 이 파일들을 직접 참조하지는 않는다.

## 어디에 있나

- 전체 프리셋 표는? → [`Preset_All.csv`](Preset_All.csv) — 컬럼: 프리셋 ID, Description, Priority, Height, Gender
- 2024-09-26 시점 스냅샷은? → [`Preset_All_260924.csv`](Preset_All_260924.csv)

## 상태

마지막 갱신 2024-09-26. 파일명에 날짜를 붙인 스냅샷이 함께 있어 어느 쪽이 최신인지 파일만으로는 알 수 없다.
